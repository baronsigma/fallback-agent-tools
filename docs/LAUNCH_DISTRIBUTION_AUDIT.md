## External references checked

- x402 Bazaar automatic discovery is facilitator/catalog-specific; route declarations include the Bazaar extension. See [x402 Foundation Bazaar documentation](https://github.com/x402-foundation/x402/blob/main/docs/extensions/bazaar.mdx).
- Registry publishing uses namespace authentication and a validation endpoint; see [official MCP Registry API](https://github.com/modelcontextprotocol/registry/blob/main/docs/reference/api/official-registry-api.md) and [server.json specification](https://github.com/modelcontextprotocol/registry/blob/main/docs/reference/server-json/generic-server-json.md).
- Smithery accepts releases through its API; see [Smithery publish API](https://smithery.mintlify.app/api-reference/servers/publish-a-server). Glama accepts GitHub repositories and can use `glama.json`; see [Glama FAQ](https://glama.ai/mcp/faq).
- x402.new describes automatic public Bazaar indexing at [List your API](https://x402.new/submit); Roundhouse describes discovery-catalog-based indexing at [Get listed as a merchant](https://roundhouseai.io/docs/guides/get-listed-as-a-merchant).
- x402-list describes endpoint submissions/probes in its [submission API docs](https://x402-list.com/api); Market402 documents free direct submission in its [FAQ](https://market402.com/faq).
