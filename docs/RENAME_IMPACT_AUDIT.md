## Centralization assessment

There is a useful central identity object, but it does not yet make a rename a safe one-file change. The generator hardcodes the MCP Registry namespace and Smithery name, `package.json` owns the npm identity, the skill and docs contain URLs, external environment and deployment paths are operator-owned, and telemetry/OpenAPI/MCP metadata currently use `fallback` namespace strings. These can be changed without changing tool IDs or HTTP routes if those stable identifiers are explicitly held fixed and generated outputs are regenerated. A rename should include a checked migration list for external listings and old URLs.

The literal-reference audit also found product namespace/host references in `LICENSE`; `src/core/config.ts`, `src/core/errors.ts`, `src/core/response.ts`, `src/core/telemetry.ts`, `src/core/registry.ts`, `src/tools/source-route/discovery.ts`, `src/surfaces/http/openapi.ts`, `src/surfaces/mcp/transport.ts`, and `src/surfaces/x402/discovery.ts`; `scripts/benchmark-source-route.ts`, `scripts/eval-source-route.ts`, `scripts/generate-discovery.ts`, and `scripts/verify-catalog.ts`; and tests `tests/contract/{bazaar-discovery-schema,config,discovery,payment-wording,source-route-discovery}.test.ts` plus `tests/integration/{http,x402}.test.ts`. Some are stable namespace strings, fallback behavior/class names, fixtures, or assertion labels rather than public product branding; review each before changing it instead of replacing every text match mechanically. Generated references live in all files under `src/generated/` and `distribution/` listed above. No `.github` marketplace/publishing workflow or standalone `x402.new`/Roundhouse/Market402 manifest exists in the repository.

## Invariants

- Keep tool IDs and MCP tool names: `source_route`, `error_route`, `request_repair`, `stop_search`.
- Keep HTTP routes: `/v1/tools/source_route`, `/v1/tools/error_route`, `/v1/tools/request_repair`, `/v1/tools/stop_search`.
- Product title, repo/package slug, hostname, telemetry namespace, and marketplace IDs may change independently, with redirects/migrations considered separately.
